# AI Document Assistant

An intelligent AI-powered document assistant that allows users to upload files and ask questions directly from their documents.

The system reads uploaded documents, understands their content, and provides accurate answers in a simple conversational way.

---

# What Users Can Do

## Upload Documents

Users can upload:

* PDF files
* DOCX documents
* TXT files

The system automatically reads and understands the uploaded content.

---

# Ask Questions from Documents

After uploading documents, users can ask questions such as:

* "What is this document about?"
* "Summarize the main points"
* "Find important details"
* "Explain this topic"
* "What does the report say about sales?"

The AI searches through the uploaded files and provides intelligent answers.

The assistant:

# Technologies Used

## Frontend

* React.js
* Vite
* Modern Responsive CSS

The frontend provides a fast, smooth, and responsive user experience across desktop and mobile devices.

## Backend

* Python
* Flask

The backend handles document uploads, AI processing, vector search, and API communication.

## AI & Search

* Google Gemini Flash Model
* FAISS Vector Search
* Sentence Transformers

These technologies help the system understand document content, retrieve relevant information

This project uses:

* Google Gemini AI
* Semantic document search
* Intelligent document retrieval
* AI-powered question answering

# Goal of the Project

The main goal of this project is to make document understanding easier by allowing users to interact with files using natural language instead of manually searching through pages.
